🔬 Technical Architecture & Data Science

AvaScry Methodology & Engineering

How high-parameter neural language models, vector geometry, and combinatorial graph heuristics power real-time discovery for Magic: The Gathering.

1. High-Dimensional Neural Embeddings

Traditional card databases query static structured fields: colors, type lines, mana costs, and substring matches on Oracle text. While syntax filters are effective for precise lookups, they cannot capture abstract functional roles, tempo pressure, or implicit mechanical relationships.

The 4,096-Dimensional Vector Pipeline

AvaScry translates every unique Oracle card into a 4,096-dimensional dense floating-point vector using an adapted Qwen 8B high-parameter transformer embedding model. The embedding prompt synthesizes:

  • Full Oracle Rules Syntax: Complete ability statements, triggers, replacement effects, and activation costs.
  • Game Mechanical Profile: Power, toughness, loyalty, speed (instant vs. sorcery), and mana curve tier.
  • Functional Role Classification: Ramp, spot removal, mass wipe, card draw engine, tutor, sacrificial outlet, or finisher.

Vectors are unit-normalized upon generation. Semantic similarity between two cards \(A\) and \(B\) is computed using the cosine similarity metric:

Cosine Similarity = (A • B) / (||A|| × ||B||)

This enables AvaScry to identify functional analogues (e.g. recognizing that Deadly Rollick and Snuff Out fulfill the same tempo role) even when their written card text shares zero identical keywords.

2. SmartDeck Curve & Synergy Mathematics

The SmartDeck Builder combines neural vector clustering with combinatorial card curve modeling to generate balanced, playable 100-card Commander lists in real time.

📊

Mana Base & Pip Ratio Balancing

Calculates the exact ratio of colored mana symbols across all 99 non-commander cards to determine land source distribution, dual land weighting, and basic land counts.

⚡

Functional Package Density

Ensures core Commander baseline requirements: 10–12 ramp spells, 10+ card advantage engines, 8–10 targeted interaction pieces, and 2–3 board resets scaled to commander mana value.

🔗

Archetype Vector Proximity

Weights candidate cards by their angular distance to the Commander's embedding vector, surfacing specific win-cons and synergistic enablers over generic good-stuff.

4. Open Access for AI Agents & Developers

AvaScry champions open web accessibility for both human deckbuilders and modern autonomous AI agents. Every resource is accessible across three distinct programmatic surfaces:

  • Human Web Surface: Interactive, accessible, dark/light-responsive HTML pages optimized for desktop and mobile devices.
  • Machine Markdown Surface: Clean, token-efficient Markdown representations (/printing/{slug}.md) tailored for direct LLM ingestion.
  • Deterministic JSON API: High-speed JSON endpoints (/printing/{slug}.json and /vector/{slug}.json) providing raw structured data and 4096-dim vector arrays.

Read more about our developer endpoints and AI manifests on our Developer Integration Hub and llms.txt.
