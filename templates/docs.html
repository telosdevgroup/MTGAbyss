1. Quickstart: Querying Cards & Data

Zero Auth • REST JSON

All endpoints are open, read-only, and served from memory with sub-millisecond response times. Append .json to any card, set, or search URL to receive a structured JSON payload.

cURL
# Fetch card details (Oracle text, mana cost, rulings, images)
curl -s "https://avascry.com/card/sol-ring.json"

# Search cards by name or syntax query
curl -s "https://avascry.com/search.json?q=counterspell&format=commander"

# Fetch expansion set metadata and card list
curl -s "https://avascry.com/set/dmu.json"
JavaScript (Fetch)
const res = await fetch("https://avascry.com/card/black-lotus.json");
const card = await res.json();
console.log(`${card.name} (${card.mana_cost || '0'}) - ${card.type_line}`);
Python (Requests)
import requests

res = requests.get("https://avascry.com/search.json", params={"q": "t:instant c:u cmc<=2"})
data = res.json()
for card in data.get("cards", []):
    print(f"{card['name']} - {card['type_line']}")

2. Core Endpoints & URL Patterns

HTTPS GET

Every resource exposes human HTML, structured JSON (via .json or Accept: application/json), and clean raw text (via .md).

Endpoint Format Description
GET /card/{slug}.json JSON Canonical Oracle card record, mana cost, type line, legalities, and printings list.
GET /printing/{slug}-{set}.json JSON Specific set printing, collector number, artist credit, flavor text, and image CDN URLs.
GET /search.json?q={query} JSON Full-text and syntax card search with syntax filters (c:, t:, f:, cmc:).
GET /set/{set_code}.json JSON Complete set checklist, release date, block info, and total card count.
GET /similar/{slug}.json JSON Mechanically related cards and synergy rankings calculated across card embeddings.

4. Cockatrice Desktop XML Simulator Database

Cockatrice v4 XML

Every expansion set published on AvaScry automatically exposes an XML feed compatible with the Cockatrice tabletop client. High-resolution art URLs and card properties are synced automatically.

How to Import into Cockatrice:
  1. Launch Cockatrice on Windows, macOS, or Linux.
  2. Navigate to Card Database → Add Custom Sets/Spoilers...
  3. Enter any set XML URL, for example: https://avascry.com/set/dmu/cockatrice.xml
  4. Click OK. Cockatrice indexes all cards and streams artwork directly from AvaScry.

6. 4096-Dimensional Neural Vector Embeddings

4096-dim Float Array

Extract raw 4096-dimensional dense embedding vectors for any Oracle card. Computed via our fine-tuned semantic model, these float arrays power semantic similarity search, mechanical clustering, and recommendation pipelines. 

# Fetch raw 4096-dim float array for any Oracle card
curl -s https://avascry.com/vector/combat-research.json

# Response Schema:
{
  "oracle_id": "c6ff5bc4-e1d1-432d-8805-4c0ef8540c77",
  "card_name": "Combat Research",
  "slug": "combat-research",
  "embedding_model": "Qwen-8B-Custom-4096d",
  "dimensions": 4096,
  "embedding": [0.0142, -0.0481, 0.0812, 0.0093, ...]
}

7. AI & LLM Ingestion (Markdown Surface)

text/markdown

AvaScry provides first-class, zero-cruft Markdown surfaces for AI agents, RAG indexing pipelines, and local LLM ingest. Request any card, printing, or set as clean Markdown with structured YAML frontmatter, or append .md directly. 

# Content negotiation with Accept header
curl -H "Accept: text/markdown" https://avascry.com/card/black-lotus

# Or append .md directly
curl https://avascry.com/card/black-lotus.md
curl https://avascry.com/set/lea.md

# AI Site Map & Discovery
curl https://avascry.com/llms.txt
