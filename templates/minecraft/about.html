About AvaScry Minecraft

Deterministic, version-pinned vanilla data atlas for Minecraft Java Edition. Structured item statistics, crafting recipes, harvest mechanics, and entities.

Mission & Purpose

AvaScry Minecraft is an independent, high-speed reference database and data atlas built for technical Minecraft players, builders, datapack designers, and automation engineers.

Our goal is to provide instantly searchable, strictly deterministic vanilla game mechanics—including blast resistance, hardness, tool harvest requirements, stack sizes, crafting formulas, and status effects—without ad bloat, slow wiki loads, or intrusive trackers.

Data Integrity & Automation

All data within AvaScry Minecraft is extracted directly from decompiled vanilla Minecraft Java Edition game data jars and registries. We maintain structured JSON and Markdown endpoints for AI agents, automation pipelines, and developer tooling via llms.txt.
